读取 workflow/constraints.md 和 workflow/simulation.md。将观察事实、推断、情景假设分别标注，引用具体页面、行和截图时间。

- 宏观分析从增长、通胀、央行路径、汇率和风险偏好展开。逐资产说明现金流、估值、久期、信用利差或商品供需的传导方向、期限、反向风险和置信程度。
- 新闻分析对照前次预期、发布值和已观察到的价格反应。区分持续冲击和一次性噪声。预期或价格反应未知时标明未知；判断已定价必须有证据。给出调整前后估计及依据。
- 同频、同币种的历史收益足够且具有代表性时，使用 Python 计算样本均值、协方差、相关性，并记录样本窗口、频率和单位。可将有依据的历史压力窗口作为联合情景。禁止将少量季度观察年化包装成可靠预测。
- 无历史数据时，使用有出处的基准、上行和下行情景，说明数值由哪些可观察变化或用户认可的假设推出。不给情景随意分配概率。记录预期收益区间、压力损失、共同风险来源。无法支持数值时请求最少的补充证据。检查方案对关键假设的敏感性。
- 引擎先最大化最差联合情景收益，再在同等最差收益下最小化换手。ROI 对应情景收益，PR 对应持仓差额及换手，RM 对应压力损失、分散与约束，RA 对应开季投资比例和风险承受能力。四项没有人为评分权重。将最优解与当前持仓、固定基准比较；收益优势不足以覆盖已知费用或估计不确定性时，news 可以在验证当前持仓全部适用约束后建议 HOLD。此时仍须保存分析和行情；使用经批准的交易门槛或决策依据，不能伪造成交。
- 比赛规则暂定按逐产品绝对权重偏差检查。止损暂按目标头寸的压力损失及售出份额的平均成本损失检查。检查实际逐笔成交和已有未实现亏损，并列出需要关注的资产和止损价格。压力损失并非成交损失上限。若官方规定按批次、资产类别或其他口径，暂停相关建议直到核实。已知费用需验证买入后的可用现金及净权重；引擎报价为毛额，费用影响可行性时不要发布该方案。未指定费用时披露不确定性。
- 报告写清数据时点、定价证据、情景及依据、资产预期与风险、前后权重和差额、实际与建议分界、约束版本、临时解释与尚未确认的事项。对平台收益差异说明大小及其是否影响下一步。
